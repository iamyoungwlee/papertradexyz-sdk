# papertradexyz-sdk

Unofficial SDKs for [Papertrade](https://papertrade.xyz) (HyperEVM perpetuals).

| Path | What |
|---|---|
| [`typescript/`](typescript) | TypeScript SDK |
| `python/` | Python SDK (planned) |

Each package carries the spec test vectors it must pass (`typescript/test/spec/`), copied from the protocol spec
maintained separately. Refresh them with `npm run sync-spec`.
